# AI Agent operations

`/health` checks the process and `/readiness` verifies the platform database and every migration checksum. A disabled or unreachable platform makes only `/v1/agents/*` unavailable; other NRAIAlgo routes continue. Runs record status, error code, model, token count and immutable agent version. The signed-in `/v1/agents/usage` route summarizes per-user runs and model tokens over 24 hours. Structured completion logs include request, correlation, run, owner, agent, tool, provider, model, duration and status, without prompts, evidence, credentials or tokens. Preferences and model observations are tenant/user scoped and stored separately from reports. Error codes include `EVIDENCE_NOT_FOUND`, `CONNECTOR_UNAVAILABLE`, `MODEL_NOT_CONFIGURED`, `MODEL_TIMEOUT`, `MODEL_UNAVAILABLE`, `INVALID_MODEL_OUTPUT`, `UNSUPPORTED_SOURCE` and `INTERNAL_FAILURE`.

First verify feature flag and URLs, then platform readiness, database migration, connector response and NVIDIA configuration. Treat repeated `MODEL_TIMEOUT` or `MODEL_UNAVAILABLE` as provider incidents; disable the feature flag if necessary. Agent runs have a 60-second lease and are marked `TIMEOUT` on the next trigger after a crash. Workflows have a two-minute lease and are reaped on the next workflow listing or trigger. A background workflow task interrupted by shutdown does not automatically resume; start a new request after inspecting prior step reports. Do not clear or rewrite historical reports during recovery.
