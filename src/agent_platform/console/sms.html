Mock sends are simulated. Accepted means the provider accepted the request; handset delivery remains unconfirmed. Choose a configured provider or an Android SIM pilot. Sending via a SIM uses your carrier plan.

Connection and limits

Use Traccar with your Android SIM

  1. Install Traccar SMS Gateway from Google Play.
  2. Connect the phone and this platform to the same trusted Wi-Fi. Open its Gateway settings and enable the local gateway.
  3. Ask the platform operator to run scripts/configure_sms.py --provider traccar_local with the phone’s local address, SIM slot and allowed test recipients. Enter the local API key only in the hidden terminal prompt; do not use the cloud token.
  4. Run the saved connection check, then request a test through your app. SIM slots are numbered 1, 2 or 3 in platform setup. Phone acceptance does not prove receipt: check the receiving phone.

This pilot sends single-segment SMS to up to ten configured test numbers. The phone must stay powered and reachable. Carrier charges and permitted use still apply. Use trusted Wi-Fi only for HTTP; do not expose the phone’s server to the public internet. This does not add WhatsApp or telephone calls.

Usage
