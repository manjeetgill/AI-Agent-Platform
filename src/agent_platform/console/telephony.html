App telephone connections

Each app connects its own carrier and pays its telephone bill. The platform answers incoming calls using the selected AI agent.

1. Select the agent and number

This is your operator test workspace. Other apps use the same flow through their backend and their own scoped service credentials.

Copy this gateway key into the app's private Asterisk bridge configuration. It is shown once. It must never go in your app's public code.

2. Connect and activate

  1. The business or app administrator authorizes its carrier and configures incoming calls to its private Asterisk gateway.
  2. Install the connection's gateway key on that gateway. It reports its connection status automatically.
  3. The platform operator reviews the carrier's number authorization and routing evidence.
  4. Refresh the status, activate, and make a real inbound test call.

Adding a number does not connect a SIM or enable call forwarding. This adapter answers FAQs and can use your app’s configured booking tools. Booking changes require the caller’s confirmation and the app’s permissions. Outbound calls and live transfers are not enabled.

3. Connect your app’s booking tools

Your app developer provides one HTTPS tool endpoint and a signing secret. The platform operator approves that app’s endpoint before it can be used. Your carrier gateway needs no AI provider key: speech runs on the platform.

READ tools run with the app’s grant. WRITE tools require an exact spoken confirmation. USER_ONLY steps stay in the business app. Protected tools also require an app-verified caller session; a phone number alone is not proof of identity.
